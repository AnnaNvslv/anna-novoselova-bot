```

budget_migration.sql     # SQL для первичного создания таблиц (запустить 1 раз)
```

## Таблицы БД

### `budget_settings`
key-value хранилище:
| ключ | описание |
|------|----------|
| `rate_eur_din` | курс EUR к динару (вручную) |
| `rate_usd_din` | курс USD к динару |
| `rate_rub_din` | курс RUB к динару |
| `savings_total_din` | общая сумма накоплений (динары) |
| `custom_categories` | JSON-массив пользовательских категорий |

### `budget_income`
Доходы по месяцам.
`id`, `month` (YYYY-MM), `source`, `amount`, `currency`, `amount_din`, `note`, `created_at`

**Источники (`source`):**
- `anya_optica` — зарплата из CRM (авто)
- `anya_other` — другой доход Ани
- `dima` — доход Димы
- `rent_house` — аренда дома (в рублях)
- `balance_start` — остаток/корректировка на начало месяца
- `other` — прочее

### `budget_expenses`
Расходы.
`id`, `month`, `category`, `subcategory`, `amount`, `currency`, `amount_din`, `is_recurring` (bool), `status` (`planned`/`reserved`/`paid`), `note`, `created_at`

**Статусы:**
- `planned` — запланировано
- `reserved` — отложено физически в конверт/папку, ещё не оплачено
- `paid` — оплачено

### `budget_savings`
История пополнений/изъятий накоплений.
`id`, `month`, `action` (`add`/`withdraw`), `amount`, `currency`, `amount_din`, `note`, `created_at`

### `budget_recurring`
Шаблоны постоянных платежей.
`id`, `category`, `subcategory`, `amount`, `currency`, `every_months`, `active`

**По умолчанию:**
| Категория | Подкатегория | Сумма | Периодичность |
|-----------|-------------|-------|---------------|
| Жильё | Аренда квартиры | 750 EUR | ежемесячно |
| Жильё | Информатика | 17 000 дин. | ежемесячно |
| Жильё | Электричество | 9 000 дин. | ежемесячно |
| Связь | Аня телефон | 1 000 дин. | ежемесячно |
| Связь | Дима телефон | 1 000 дин. | ежемесячно |
| Садик | Садик | 44 000 дин. | ежемесячно |
| Ваня Концерта | Врач+таблетки | 8 100 дин. | раз в 2 месяца |

## Логика

### Курсы валют
Все суммы хранятся в оригинальной валюте + пересчёт в динары (`amount_din`). Курсы задаются вручную в ⚙️ Настройки. При изменении курса старые записи **не пересчитываются**.

### Синхронизация с CRM
Кнопка 🔄 или автоматически при открытии:
1. Берёт завершённые приёмы за месяц → суммирует `consultation_price`
2. Берёт заказы с `counts_for_salary=true` → 10% от суммы
3. Сохраняет/обновляет запись `anya_optica` в `budget_income`

### Постоянные платежи
При первом открытии месяца автоматически копирует шаблоны из `budget_recurring` в `budget_expenses`.

### Накопления
Общий остаток хранится в `budget_settings.savings_total_din` и пересчитывается при каждом действии. Ручная корректировка — в ⚙️ Настройки.

## Интерфейс — вкладки

- **📊 Обзор** — сводная плашка + доходы + расходы + накопления
- **📋 Транзакции** — все операции месяца одним списком с фильтрами
- **📈 Аналитика** — сравнение с прошлым месяцем + структура расходов

## Цветовая идентификация

| Цвет | Значение |
|------|----------|
| 🟢 Зелёный | Оплачено / доходы / положительный остаток |
| 🟡 Персиковый | Отложено / предупреждение |
| 🔴 Красный | Перерасход |
| 🟣 Лиловый | Накопления |
| ⚠️ Жёлтая рамка | Накопления не пополнялись в этом месяце |

## Первый запуск

1. Выполнить `budget_migration.sql` в Supabase → SQL Editor
2. Открыть budget.html
3. ⚙️ → проверить курсы валют
4. 🔄 — синхронизировать зарплату из CRM

## Соглашения

- Версионирование скриптов: `?v=2` (увеличивать при правках)
- Все суммы хранить в оригинальной валюте + `amount_din` для расчётов
- При добавлении источников дохода → `INCOME_SOURCES` в `budget-config.js`
- При добавлении статусов → `EXPENSE_STATUS` в `budget-config.js`
